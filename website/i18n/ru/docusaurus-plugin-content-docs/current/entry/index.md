# Обзор Entry Web UI

Entry Web UI — это локальная панель управления для Engram. Используйте ее для настройки корней памяти, привязки ИИ-агентов, точной настройки маршрутизации, просмотра дубликатов, проверки графа памяти и отладки конфигурации времени выполнения без ручного редактирования файлов JSON.

## Когда использовать

- Первая настройка рабочей области или корня глобальной памяти
- Привязка или отвязка ИИ-агентов без необходимости помнить флаги CLI
- Настройка параметров маршрутизации, графа, векторного поиска и вариантов правил
- Просмотр дублирующихся или конфликтующих воспоминаний
- Инспектирование графа памяти
- Отладка разрешенной конфигурации, путей и обнаружения Git

## Локальная модель доступа (Local-only)

Панель работает на вашем компьютере. Это не облачный сервис. Закрывайте сервер по окончании работы в целях безопасности.

<RiskCallout level="risky">
Панель управления Entry является локальной. Считайте её открытой во время настройки памяти, а затем закройте сервер из нижней части боковой панели по завершении работы.
</RiskCallout>

## Отношение к командам CLI

Каждый видимый элемент управления сопоставляется с командой CLI или ключом конфигурации. Если существует эквивалент CLI, справочник полей указывает его. CLI остается источником истины для сценариев и автоматизации.

## Навигация и URL-маршрутизация

Entry Web UI использует URL `#hash`-маршрутизацию, поэтому каждую вкладку можно добавить в закладки, перезагрузить или открыть через историю браузера:

- `#config` — Construct
- `#author` — Git
- `#upgrade` — Updates
- `#recall` — Memories
- `#review` — Review
- `#maintain` — Core
- `#connect` — Connections

Боковая панель включает раздел **Workspace** для элементов управления на уровне рабочего пространства и показывает значок с числом ожидающих элементов на вкладке **Review**, когда результаты проверок, отложенные кандидаты или квитанции ожидают сортировки. На узких экранах боковая панель сворачивается в мобильную выдвижную панель, которую можно закрыть кнопкой закрытия или клавишей `Escape`.

## Личность автора Git

Engram может хранить глобального автора и необязательное переопределение для рабочего пространства. Порядок разрешения: рабочее пространство, глобальный, затем резервный Git только для чтения. Настройки влияют только на будущие воспоминания; переопределение рабочего пространства никогда не меняет глобальную конфигурацию Git. Для синхронизации с глобальным Git или миграции устаревших воспоминаний используйте явный план и подтверждение.

```bash
engram author show
engram author set --name "Jane Doe" --email "jane@example.com"
engram author unset --scope workspace
engram author sync-git-global --plan
engram author sync-git-global --confirm
engram author migrate-memories --plan
engram author migrate-memories --confirm
```

Прочитайте полное [руководство по настройкам автора Git](../operations/git-author-settings.md).
